# Mobile tasks and notes

The mobile app has a lightweight task and notes list for project reminders. Open it from the tasks icon in the threads-list header. Choose a project, enter a short task or note, set its status to **To do**, **In progress**, or **Completed**, and add it to the list.

When a thread is open, choose **Tasks and notes** from the thread actions menu. The list there shows only reminders for that thread's project and assigns new reminders to that project automatically.

Items are grouped by status and show their current status beside the project name. Tap the status icon to complete an unfinished item or return a completed item to **To do**. Use the edit action to change the text, project, or status, and use the trash action to delete it.

Tasks and notes are stored on the mobile device. They do not change project files or sync to another device.
