# Mobile tasks and notes

The mobile app has a lightweight task and notes list for project reminders. Open it from the tasks icon in the threads-list header, then tap the compose button in the lower-right corner. The composer lets you enter a short task or note, attach screenshots or images, and choose its project and **To do**, **In progress**, or **Completed** status. Unsent text and attachments are saved on the device and restored when you return to the composer.

When a thread is open, choose **Tasks and notes** from the thread actions menu. The list there shows only reminders for that thread's project and assigns new reminders to that project automatically.

Items are grouped as **In progress**, **To do**, then **Completed**. The most recently created or changed item appears first in each group, and each compact row shows up to three lines of text plus its current status, project, and attachment count; image thumbnails stay out of the list. Tap anywhere on the row to open the full task text, project, status, timestamps, and attached images. Swipe an item right to send it to an agent: the picker shows unsettled threads from the same project by default, and its **Settled** option shows finished threads instead. Choose a thread or start a new one, and the task text and images are placed in the composer for review before sending. Swipe left to mark an item **In progress**. Tap the status icon to complete an unfinished item or return a completed item to **To do**. The details screen has actions to copy or edit the task, and a delete action with confirmation at the bottom. Editing opens the same composer used for creation so you can change the text, images, project, or status.

Tasks and notes are stored on the mobile device. They do not change project files or sync to another device.
