# Mobile tasks and notes

The mobile app has a lightweight task and notes list for project reminders. Open it from the tasks icon in the threads-list header, then tap the compose button in the lower-right corner. The composer lets you enter a short task or note and choose its project and **To do**, **In progress**, or **Completed** status.

When a thread is open, choose **Tasks and notes** from the thread actions menu. The list there shows only reminders for that thread's project and assigns new reminders to that project automatically.

Items are grouped by status and show their current status beside the project name. Swipe an item right to mark it **Completed**, or swipe it left to mark it **In progress**. Tap the status icon to complete an unfinished item or return a completed item to **To do**. The edit action opens the same composer used for creation so you can change the text, project, or status; use the trash action to delete it.

Tasks and notes are stored on the mobile device. They do not change project files or sync to another device.
