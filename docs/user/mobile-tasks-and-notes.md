# Mobile tasks and notes

The mobile app has a lightweight task and notes list for project reminders. Open it from the tasks icon in the threads-list header. Choose a project, enter a short task or note, and add it to the list.

When a thread is open, the same tasks icon appears with the files, terminal, and source-control actions. Opening the list there shows only reminders for that thread's project and assigns new reminders to that project automatically.

Tap the circle beside an item to complete it or return it to the open list. Use the trash action to delete it.

Tasks and notes are stored on the mobile device. They do not change project files or sync to another device.
